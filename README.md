# study-activity-tracker
Python project to track use of various desktop applications and websites in real time. Implemented activity analysis and visualization over a daily and weekly period, as well as website blocking. 

Functions implemented:
- Real-time storage and tracking of the tasks currently being done on a Windows system.
- Daily and weekly activity analysis of most used desktop applications as well as websites displayed akin to fitness tracking apps to track study and other activities, increasing productivity.
- Website blocking functionality enabled; user may input the urls of websites they wish to avoid during productive hours and block them for that duration.
- Tracking and blocking time period can be set by the user.
